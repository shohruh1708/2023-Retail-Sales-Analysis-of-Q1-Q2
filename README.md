
# 2023 Retail Sales Analysis Dashboard

## Overview
This Power BI dashboard provides an interactive analysis of 2023 retail sales performance for Q1 and Q2. The project focuses on sales trends, regional performance, product contribution, and profitability using dynamic visualizations and slicers.

## Features
- KPI cards for:
  - Total Sales
  - Total Profit
  - Total Orders
  - Total Cost

- Interactive visuals:
  - Sales by Region
  - Monthly Profit Analysis
  - Product Sales Distribution
  - Sales Trend by Date
  - Product Count & Sales Comparison

- Dynamic slicers for:
  - Product
  - Region
  - Weekday
  - Quarter
  - Month

## Tools Used
- Power BI
- DAX
- Power Query

## Dashboard Highlights
- Modern dark-themed UI design
- Interactive filtering experience
- Clear KPI-focused layout
- Business performance insights for retail sales data
